# studentportal

BRDP Mahavidyalaya Student Information System & Fee Report Operational Portal.

## Features
- **Student Directory & Master User Management**
- **Semester 1 to Semester 6 Fee Matrix Generator**
- **Prioritized Student Fee Calling List Exporter**
- **Universal Filters & Instant Keyword Search**
- **Direct 1-Click Excel (.xlsx), CSV (.csv), and JSON (.json) Exports**
- **Strict View-Only Reporting Operational Mode**

## Setup & Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Nitinkumr007/studentportal.git
   cd studentportal
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` and set environment variables:
   ```bash
   cp .env.example .env
   ```
4. Start the server:
   ```bash
   npm start
   ```
5. Open http://localhost:3000 in your browser.
